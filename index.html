📊 Dashboard IoT Firebase

Pantau sensor ESP32 & kontrol perangkat secara real-time — data dibaca langsung dari Firebase Realtime Database kamu.

Masukkan URL database Firebase lalu klik "Mulai Pantau".

🔑 Konfigurasi Firebase

📖 Panduan Setup Firebase (4 langkah)
  1. Buat proyek Firebase — buka console.firebase.google.com → Add project → beri nama (mis. iot-suhu-ku) → Create.
  2. Aktifkan Realtime Database — menu kiri Build → Realtime Database → Create database → pilih lokasi (mis. asia-southeast1) → pilih mode test (aman untuk belajar) → Enable.
  3. Salin URL database — di tab Data, salin URL yang berbentuk https://NAMA-PROYEK-default-rtdb.asia-southeast1.firebasedatabase.app → isikan ke kolom URL Database di atas.
  4. Klik 🧪 Tes Koneksi — jika muncul "✅ Terhubung!", klik 🟢 Mulai Pantau. Data sensor ESP32 akan tampil real-time.
Di sisi ESP32: buka template proyek Firebase di Lab Proyek (mis. "IoT Suhu & Kelembaban Firebase" atau "Servo Kendali dari Firebase"), lalu isi DATABASE_URL dengan URL database (cukup URL saja — tanpa apiKey/secret). Template memakai HTTP REST bawaan ESP32 (HTTPClient), tanpa library Firebase tambahan. Setelah kode dijalankan (Wokwi/ESP32 asli), ESP32 otomatis menulis data ke path seperti /sensor/suhu, /sensor/kelembaban, /jarak/cm, /cahaya/nilai_adc, /gas/nilai_adc — dan dashboard ini membacanya.
Path kontrol keluar: servo menulis ke /servo/sudut, LED RGB ke /rgb/merah, /rgb/hijau, /rgb/biru. ESP32 harus memantau path tersebut (template sudah menyediakannya).
Rules: mode test = siapa pun boleh baca/tulis (cocok untuk belajar, JANGAN untuk produksi). Tanpa secret/apiKey, rules harus tetap mode test supaya browser bisa membaca & menulis.
💡 Isi URL database Firebase kamu di atas (mis. dari proyek ESP32 "IoT Suhu & Kelembaban Firebase"), lalu klik Mulai Pantau. Data akan tampil real-time di sini.

PERUNDANG-UNDANGAN K3

Buka setiap panel untuk membaca penjelasan dan tautan sumber resmi.

UU No. 1 Tahun 1970
Undang-Undang Pokok Keselamatan Kerja merupakan landasan utama (payung hukum) penerapan Keselamatan dan Kesehatan Kerja (K3) di Indonesia. Undang-undang ini memuat syarat-syarat keselamatan kerja secara umum guna mencegah kecelakaan dan penyakit akibat kerja di segala tempat kerja.
🔗 Baca Dokumen di JDIH Kemnaker
UU No. 13 Tahun 2003
Undang-Undang Ketenagakerjaan khususnya pada Pasal 86 mengatur hak pekerja/buruh atas perlindungan keselamatan dan kesehatan kerja, serta Pasal 87 yang mewajibkan perusahaan/pemberi kerja untuk menerapkan Sistem Manajemen K3.
🔗 Baca Detail Regulasi (BPK)
PP No. 50 Tahun 2012
Penerapan Sistem Manajemen Keselamatan dan Kesehatan Kerja (SMK3). Peraturan Pemerintah ini menjabarkan lebih rinci amanat UU No. 13/2003 pasal 87, menggarisbawahi bahwa setiap perusahaan yang mempekerjakan >100 orang atau memiliki potensi bahaya tinggi wajib menerapkan SMK3 yang terintegrasi.
🔗 Sumber Hukum JDIH
Permenaker No. 12 Tahun 2015
Keselamatan dan Kesehatan Kerja Listrik di Tempat Kerja. Peraturan level kementerian inilah yang paling relevan bagi praktisi elektro. Permenaker ini menetapkan standar teknis kelistrikan demi meminimalisasi bahaya sentuh langsung/tak langsung, serta mewajibkan adanya personil bersertifikat Ahli K3 Listrik.

⚠️ 5 Aturan Emas Keselamatan Listrik (EN 50110)

  1. Putuskan koneksi sepenuhnya (Disconnect completely).
  2. Amankan dari re-koneksi tak sengaja (LOTO - Lock Out Tag Out).
  3. Verifikasi bahwa instalasi sudah tanpa tegangan (Gunakan voltage tester).
  4. Laksanakan pembumian (Grounding) dan hubung singkat (Short-circuiting).
  5. Berikan proteksi/perlindungan pada komponen di sekitarnya yang masih bertegangan.
Sumber: CENELEC EN 50110 - Operation of electrical installations.
